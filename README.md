# Owl Message Board - The Odin Project

## Description

This project is part of [The Odin Project](https://www.theodinproject.com) curriculum. Owl Message Board is a simple web application that allows users to display and add messages to a message board. Messages are displayed with the user and the date they were added. The theme of the application is based on the universe of Harry Potter.

## Installation

1. Clone the GitHub repository:
```sh
git clone git+https://github.com/Louis-dub/owl_message_odin.git
```
2. Navigate to the project directory:
```sh
cd owl_message_odin
```
3. Install the dependencies:
```sh
npm install
```

## Usage

1. Start the server:
```sh
node index.js
```
2. Open your browser and go to [http://localhost:3000](http://localhost:3000).

## Features

- **Display Messages**: Messages are displayed on the homepage with the user and the date they were added.
- **Add Messages**: Users can add new messages via a form.

## Technology

- **Express**: Web framework for Node.js.
- **EJS**: Template engine for generating HTML pages.
- **CSS**: For styling the page.
